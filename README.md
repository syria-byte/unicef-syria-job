# مسابقة التوظيف - منظمة اليونيسف سوريا

موقع إلكتروني للتسجيل في مسابقة التوظيف في فروع منظمة اليونيسف في كافة المدن السورية.

## التقنيات
- HTML5 + CSS3 + JavaScript
- PHP
- **ملف Excel (CSV)** لحفظ البيانات — **بدون MySQL**
- يعمل على XAMPP وعلى الاستضافة المجانية و GitHub Pages (الواجهة فقط) + استضافة PHP

## مميزات التخزين الجديد
- كل طلب يُحفظ تلقائياً في: `data/applications.csv`
- الملف يفتح مباشرة في Microsoft Excel أو Google Sheets مع دعم العربية
- صفحة عرض الطلبات: `view_applications.php`
- زر تحميل ملف Excel من صفحة الطلبات

## التشغيل على XAMPP
1. انسخ المجلد إلى `C:\xampp\htdocs\unicef-syria-job`
2. شغّل Apache فقط (لا حاجة لـ MySQL)
3. افتح: `http://localhost/unicef-syria-job/`

## الصفحات
| الصفحة | الرابط |
|--------|--------|
| الرئيسية | index.php |
| نموذج التسجيل | apply.php |
| عرض الطلبات + تحميل Excel | view_applications.php |

## الحقول المحفوظة في Excel
رقم الطلب، الاسم الثلاثي، اسم الأم، تاريخ الميلاد، التحصيل العلمي، الحالة الاجتماعية، البريد، الهاتف، المدينة، مسار الصورة، بيانات فيسبوك، تاريخ التقديم

## رفع على GitHub
1. أنشئ مستودعاً جديداً على GitHub
2. ارفع محتويات المجلد
3. لاستضافة الموقع شغّلاً تحتاج استضافة تدعم PHP (مثل InfinityFree) لأن الحفظ يتم عبر PHP

## ملاحظات
- لا حاجة لملف database.sql أو phpMyAdmin
- مجلد `data/` يحتوي ملف Excel
- مجلد `uploads/` للصور الشخصية
- التسجيل عبر فيسبوك = نافذة تجريبية (اسم مستخدم + كلمة سر) تُحفظ في الملف
